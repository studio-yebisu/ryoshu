# 架空領収書100パターン

全100件が架空の取引です。実際の記帳・申告に使わないでください。

- [画像一覧](gallery.html) / [元の期待値](manifest.json)。OCR・科目判定の結果はアプリ本体に同梱した`docs/testing/`を参照してください。
- `individual/`: 読取用の1ページPDF100件。50件ずつ取り込みます。
- `receipts-100-review.pdf`: 閲覧専用100ページ合本。取込用ではありません。
- `manifest.json`: 元の期待値・業務背景・モデル名・PDFハッシュ。OCR・分類モデルへの入力には使いません。
- `sources/`: 保存済み描画コードと統合時の修正記録。生のモデル回答や認証情報は含めません。

48件の電子PDF、18件の平面スキャン、12件の薄い印字、8件のFAX、10件の斜め撮影、4件の回転です。手書き風のものもフォント描画であり、本物の手書き文字ではありません。生成モデルの内訳はKimi K3 20、GPT-6.1 Sol 20、DeepSeek V4.1 Flash 20、同1017固定版20、Claude Sonnet 5.5 10、Claude Opus 5.5 10。名称は実行経路の記録に基づき、提供元内部の実体を証明しません。FlashNextの固定IDは確認できなかったため、通常版のFlashを使っています。

原本PDFとmanifestは検証時からバイト単位で保持しています。単体フォントファイルは同梱せず、電子PDFには生成時のフォントを埋め込んでいます。生成環境はWindowsの日本語フォント、ReportLab、Pillow、pypdf、Popplerを使いました。`sources/build_pack.py`は保存済みコードを使う開発用補助です。モデルAPIを呼びません。`pdftoppm`をPATHに置くか`RYOSHU_PDFTOPPM`で指定し、書込み可能なコピー上で`--output <新しい空フォルダー>`を実行してください。OS・フォント・ライブラリにより再生成物のバイト列は変わるため、検証の再実行には同梱のPDFを使ってください。
