## 結果の概要

v1.4で既存の架空100件を検証し、編集前の初期出力は、円額95/95、外貨の円額未確定2/2（返金3件は金額比較から除外）、日付99/100、支払先85/100、通常の科目提案44/48、特別な処理52件中42件、全100件の科目または処理判定86/100、印字税額51/52、正しい空欄11/11でした。税額の残り37件は評価対象外です。処理時間は22分36.711秒で、新しいアプリプロセスの最初のアップロード直前から全件終了を一覧で確認するまでを測り、50件ずつ2回のアップロード・OCR・ローカルモデルを含み、初回準備・ダウンロード・利用者の確認・CSV・採点を除外しています。

llama.cppへの変更とモデルの種類の変更を同時に行ったため、差異を実行環境だけの効果とする検証ではありません。アプリは新規起動ですが、以前の実行でOS・ディスクキャッシュは温まっていました。同じ架空100件の開発・回帰検証で、未知の実物領収書の正確さや、OCR・モデル単体の精度ではありません。結果は利用者が編集する前の候補で、税務処理の正しさや脆弱性の不存在を保証するものではありません。

## 測定方法と評価の範囲

評価したのは、OCR、PDF文字層と抽出値の照合、ローカルモデル、根拠確認と科目条件を経た、人が編集する前のアプリの初期出力です。rootが既存の期待値に照らして採点しました。利用者が確認・修正した最終帳簿ではありません。

OCR単体や、モデルが最初に返した応答だけを測った精度ではありません。アプリ全体の初期候補を評価しています。

新しいアプリプロセスで測り、以前の開発実行によりOS・ディスクキャッシュが温まった状態です。最初のアップロード要求の直前から、全100件の終了を一覧で最初に確認するまでを計測しました。50件ずつ2回のアップロード、実行環境とモデルの確認・初回読込、OCR、PDF文字層の処理、ローカルモデル、根拠照合と科目条件を含みます。導入・初回準備・ダウンロード・アプリ起動・後の詳細取得・利用者の確認・CSV作成・採点は含みません。終了時刻には一覧を確認する間隔による誤差があります。

実測した経過時間と一覧を確認した間隔は次のとおりです。

| 経過時間（秒） | 一覧を確認した間隔（秒） |
| ---: | ---: |
| 1356.711236999996 | 1 |

旧構成からllama.cppへの変更と、Qwen3 4B Thinking 2507から公式Qwen3-4B hybrid GGUFへの変更を同時に行っています。差異の原因を実行環境だけに帰属させる比較ではありません。

開発と回帰検証に使ってきた既存の架空100件を、同じ検証機で1回処理した結果です。未知の実物領収書における一般的な正確さや速度を示すものではありません。

金額は、非負の円額を数値で読み取る95件を完全一致で評価しました。外貨の2件は円額を確定せず空欄にできるかを別に評価し、返金の3件は金額比較から除外しました。

科目は、通常の科目提案を期待する48件で、正式な許容科目の一覧に含まれるかを評価しました。保留・登録停止・資産確認などの特別な処理を期待する52件はこの48件には含めず、それぞれの扱いを別に評価しています。全100件については、科目または処理判定が期待と一致するかも併記します。

税額は、印字された数値を読み取る52件と、正しく空欄にする11件を分けて評価しました。残る37件は評価対象外で、件数だけを示し、成功率は付けません。税務上の最終判断は利用者と税理士が行います。

この結果は、税務処理がすべて正しいことや、脆弱性が存在しないことを示すものではありません。

実行環境・モデル・設定・ソースの固定情報とハッシュは、ダウンロードできる結果JSONに記録しています。

## 確認済みの制約と個別の差異

sqlcipher3 0.6.4のwheelはSQLCipher 4.19／OpenSSL 3.6.0を使用し、変更・修正は加えていません。公式の助言情報と静的なprovider経路を限定的に確認しただけで、脆弱性や悪用可能性がないことを証明するものではありません。別の45パッケージに対する依存脆弱性照合で既知の一致が0件だったことも、包括的な安全性の保証ではありません。

同じ架空100件を同じ検証機で1回測った開発・回帰検証です。未知の実物領収書や、一般的な正確さ・速度を示す結果ではありません。

すべて人が編集する前の初期候補です。支払先・日付・金額・税額・科目を原本と照合してください。処理の完了は内容の確認を意味せず、税務上の最終判断は利用者と税理士が行います。

V011には納品日2024-05-22と発行日2024-05-20があります。アプリは期待した納品日ではなく発行日を選びました。未払の書類として登録を止める判定は期待どおりです。

V013は印字された税額553を期待しましたが、OCRで税額ラベルを判読できず、アプリは空欄にしました。数字だけを根拠に税額を推測していません。他の37件は評価対象外です。

V032・V067・V093は、許容する正式科目の外注費などとは別の正式科目である外注工賃を選びました。V073は曖昧な定期購読として科目を保留しました。期待値・科目の別名・評価方法を結果に合わせて変更していません。

支払先の候補は履歴から変化しました。V051は改善し、V089は支店名の末尾を省略し、V094は購入者と販売者の会社の選択が異なりました。いずれの名称も原本と照合してください。

帳簿・保存済み原本・バックアップは既存の暗号化設計で保護しますが、ダウンロードしたCSVと書き出した原本は平文です。保存先と共有先を管理し、税務上の正しさが自動確認されたとは扱わないでください。
