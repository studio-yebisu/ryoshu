# 保存データと通信

アプリは`127.0.0.1`にのみ待ち受け、AIの接続先は`127.0.0.1:11434`のOllamaです。アプリのPythonプロセスでは、監査フックで外向きソケット接続とDNS照会を拒否します。OCRはダウンロード済みキャッシュだけを使います。外部OCR・クラウドLLMへの自動フォールバック、アクセス解析、アカウント連携はありません。

セットアップ時のパッケージ・モデル取得にはネット接続を使います。ブラウザーやOllama自体の更新確認を止める仕組みではありません。

`%USERPROFILE%\StudioYebisu\ReceiptLedger\data`に、SQLite、領収書原本、プレビューを保存します。SQLiteにはOCR本文、元のAI候補、利用者の修正、事業概要、支払先ルール、確定仕訳、変更履歴も含まれます。OCRモデルは同階層の`cache`、LLMはOllamaのモデル保存先です。

このアプリはデータやバックアップZIPを暗号化しません。PCのアカウント・ディスク・バックアップ先の権限で管理してください。CSVにも取引内容が入ります。サーバーをLANやインターネットへ公開する構成は対象外です。

同梱の`samples/receipts-100-v2`と`docs/testing`は架空の検証用データです。実際の利用者の領収書、DB、モデル、キャッシュ、端末固有の実行ログを公開リポジトリへ含めません。
