# 導入・更新・起動

[README](../README.md) / [動作要件](REQUIREMENTS.md) / [使い方](GUIDE.md)

## 初回だけ行うこと

1. [Ollama Windows版](https://ollama.com/download)を導入します。PC内でAIを動かすために使います。
2. [Ryoshuの配布ZIP](https://github.com/studio-yebisu/ryoshu/releases/tag/v1.1.0)を新しいフォルダーに展開します。
3. `Ryoshu.cmd`をダブルクリックします。コマンド画面でモデルの利用条件を確認して続行すると、必要な実行環境とモデルを自動で準備します。
4. 準備が終わるとブラウザーが開きます。復元用パスワードを2回入力して設定し、安全な場所に保管します。次回以降はWindowsが自動で帳簿を開くため、毎回の入力は不要です。

Pythonやuvを別途用意する必要はありません。準備ツールは公式のuv 0.13.5を固定し、ZIPと実行ファイルのSHA-256を照合してから使います。Python 3.12.15・64bitをアプリ専用の保存先へ取得し、固定版・ハッシュ付きの依存を導入します。管理者権限は不要です。

初回はネット接続と数GB以上の空き容量が必要です。Qwen3 4Bは約2.5GBです。IndraのOCR重みには利用制限があります。[条件と原文](../THIRD_PARTY.md)を確認してから続行してください。

初回準備だけをやり直す場合は`初回セットアップ.cmd`を使います。取得に失敗した場合は、ネット接続・保存先・空き容量を確認し、同じ手順で再試行できます。準備後の領収書処理は外部OCR・外部AIへ切り替えません。

## 毎回の起動と終了

`Ryoshu.cmd`または`起動.cmd`をダブルクリックします。起動リンクにはこのPCのアプリを開くための短時間の認証情報が含まれます。アドレスだけを直接開いて「起動リンクから開いてください」と表示された場合も、`Ryoshu.cmd`から開き直してください。

終了は`停止.cmd`です。ブラウザーを閉じるだけでは処理は終了しません。停止操作は対象のプロセスを照合し、Ollamaや帳簿ファイルは削除しません。別アプリが8766番を使っている場合は停止・上書きしません。

## v1.1系から更新する

旧版で暗号化バックアップを保存し、`停止.cmd`で終了します。新しい配布ZIPを別のフォルダーへ展開し、`Ryoshu.cmd`を起動してください。同じWindows利用者・既定の保存先なら、暗号化済みの帳簿を引き継ぎます。元のフォルダーや帳簿を上書き・削除する必要はありません。起動後は原本・件数・保存済みの修正を確認してください。

税額・科目の修正は新しく読み取る候補に適用します。保存済みの修正や確認済み仕訳を自動で書き換えません。未確認の旧候補に新しい読み取り処理を適用したい場合は、個別の再試行を使い、原本と確認してください。

## v1.0系から更新する

1. 旧版でバックアップを保存し、安全に保管します。旧ZIPは暗号化されていません。
2. `停止.cmd`で旧版を終了します。
3. 新しい配布ZIPを別のフォルダーへ展開し、`初回セットアップ.cmd`、続いて`Ryoshu.cmd`を実行します。
4. 復元用パスワードを設定し、移行の完了を待ちます。原本・全行を照合してから切り替えます。
5. 内容を確認して、新しい暗号化バックアップを保存します。

古いPython環境は削除せず `venv-before-update-*` として残します。`data`、`restored`、`cache`を移動・削除しないでください。旧版は保護済み帳簿を開けません。原本が不足・不一致なら切替前に止まり、理由を表示します。[暗号化の説明](SECURITY-DESIGN.md)

## バックアップ・復元

「設定・バックアップ」で「暗号化バックアップを保存」を選び、復元用パスワードを入力します。`.ryoshubak`を保存し、パスワードとは別の安全な場所へ保管します。Chrome/Edgeでは保存先を選んで書き込みます。対応しないブラウザーは256MBまでです。

原本が不足・破損している場合は、救出用の設定で残ったデータだけを保存できます。完全なバックアップではなく、省いた原本はこのバックアップからは復元できません。不足件数は復元後にも表示します。

戻すときは`バックアップから復元.cmd`からファイルを選び、パスワードを入力します。旧ZIPも選べます。その場合は新しい復元用パスワードと確認入力を行います。元の帳簿を上書きせず、新しい`restored/<日時と識別子>/data`へ復元します。復元後は、そのフォルダー内の`この帳簿を開く.cmd`から開けます。

パスワードを忘れても、Windowsで帳簿を開ける間は「設定・バックアップ」で再設定できます。**再設定しても、過去のバックアップのパスワードは変わりません。** その復元には作成当時のパスワードが必要です。再設定後は新しいバックアップを作成してください。

## 困ったとき

モデルに接続できないときはOllamaを起動します。クラウド版や不明なモデルは拒否します。`qwen3:4b`の準備は初回セットアップで行います。読み取りに失敗した明細は、画面から再試行できます。

Windowsで自動解除できない場合は復元用パスワードを使います。保護情報が破損・欠落している場合や、復元に失敗した保存先は空の帳簿へ切り替えません。バックアップから新しい保存先へ復元してください。

**Windowsの鍵と復元用パスワードの両方が使えなくなると、帳簿を復元できません。** 開発者にも解除する手段はありません。書き出したCSV・原本と旧版のZIPは暗号化されない通常のファイルなので、保存先・共有先を管理してください。

診断ログは`%USERPROFILE%\StudioYebisu\ReceiptLedger\runtime`です。実際の領収書、帳簿、復元情報、パスワード、バックアップを公開Issueへ貼らないでください。
