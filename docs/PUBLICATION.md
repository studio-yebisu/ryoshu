# 公開準備の検証範囲

2026-10-21のローカル公開候補です。公開先の候補名は`studio-yebisu/ryoshu`。外部リポジトリの作成・push、Release、GitHub Pagesへのdeployはこの準備に含めていません。

## 構成

アプリ本体、科目初期値・移行履歴、固定依存、起動スクリプト、テスト、導入・利用・ライセンス資料、架空の100件、公開用の比較結果を独立したGitルートへまとめています。元の試作と通常の帳簿はそのまま保持しています。

領収書原本と元のmanifestは検証時のハッシュで確認します。公開結果からは端末固有パスとローカル記録IDを除きます。原本のSHA、期待値、自動候補、採点、実行元、手動補正、元ソースのSHAは残します。6件のCSV例には架空のローカル証憑IDがありますが、実在の利用者や取引の記録ではありません。

ソースZIPはGitの対象ファイルだけから作り、モデル重み、venv、帳簿DB、個人の領収書、認証情報、ログ、キャッシュ、元ワークスペースの履歴を含めません。

## 検査

- 単体・API検査: 既存67件を独立リポジトリでも実行。
- 架空6件のCSV統合検査: 4形式、6件・7仕訳行、借貸299,095円で照合。
- `scripts/check_publication.py`: 100原本ハッシュ、期待値、画像とリンク、ZIP内容、公開採点集計、端末パス・秘密情報らしい文字列・混入ファイルを点検。
- JavaScript構文、PowerShell構文、ブラウザーの名称・検証ページ・検索・画像・リンクを確認。
- 新しい配布候補のOCR・意味判断・会計モジュールと科目初期値を元の100件検証時のハッシュと照合。

この文書の各項目の実行結果は`dist/verification.json`に保存します。実行できなかったものは同ファイルで未確認として記録します。GitHub Actionsの定義は用意していますが、GitHub上で成功したという意味ではありません。
