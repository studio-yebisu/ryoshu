# 読み取り・科目候補の確認方針

[README](../README.md) / [使い方](GUIDE.md) / [収録科目](ACCOUNTS.md)

Ryoshuは領収書の文字読み取り、勘定科目の候補作成、経費帳の下書き、CSV作成を補助するツールです。AI候補を、そのまま必要経費の算入可否や税務上の確定判断として扱わないでください。

## ご自身による確認と、税理士への確認

1. 原本と照合し、日付・支払先・金額・勘定科目・購入内容を必ずご自身で確認します。
2. 業務での用途、私用分の有無と事業割合、その根拠、支払元、会計ソフトへ出す税区分を確認します。
3. 本アプリの利用方針として、申告や税務処理に用いる前に、科目・経費算入・按分・資産計上・消費税などの最終判断を税理士に確認してください。

取り込んだだけの明細は「未確認」です。個別の確認操作、または原本と内容を確認した旨のチェックを伴う一括操作で「確認済み」にします。freee・MFクラウド・弥生向けの仕訳CSVには確認済みの明細を使います。未確認の明細も保存できる汎用CSVは、状態を含む下書き・確認用の一覧です。

**「確認済み」は利用者が確認操作をした状態です。税理士の承認、確認の実施証明、税法への適合を表す状態ではありません。** 税理士への相談・確認そのものは、利用者が別途行います。Ryoshuが相談先へ自動送信することはありません。

## 法的な適否について

国税庁は、税務代理・税務書類の作成・税務相談という税理士業務を原則として税理士等に限ること、反復継続する業務は必ずしも有償である必要がないことを説明しています。注意書きや無料配布だけで、個別の提供行為の適法性が保証されるわけではありません。

これは一般的な業務範囲の参照であり、Ryoshuの機能・提供方法について適法性を確認した法律意見ではありません。Ryoshuは税務相談・申告代理・申告書の作成を提供するものとして案内せず、法的な適否や税務上の取扱いを保証しません。本アプリの機能・提供方法について、弁護士・税理士による法務審査は受けていません。
