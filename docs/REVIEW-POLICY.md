# 読み取り・科目候補の確認方針

[README](../README.md) / [使い方](GUIDE.md) / [収録科目](ACCOUNTS.md)

Ryoshuは領収書の文字と数字を読み取り、科目の候補・経費帳の下書き・CSVを作ります。AIが提示した内容を、そのまま必要経費への算入や税務上の結論に使わないでください。

## 利用者が確認すること

1. 原本を開き、日付・支払先・金額・購入内容・勘定科目を照合します。
2. 業務での用途、私用分の有無、事業割合とその根拠、支払元、会計ソフトへ出す税区分を入力して確認します。
3. 申告や税務処理に使う前に、科目・経費算入・按分・資産計上・消費税などの最終判断を利用者と税理士で行います。

取り込んだ直後の状態は「未確認」です。明細を個別に確認するか、一括操作で原本との照合を明示すると「確認済み」になります。freee・MFクラウド・弥生向けの仕訳CSVには確認済みを使います。未確認を含む汎用CSVは、状態を確認するための一覧です。

**「確認済み」は利用者が操作した状態を表し、税理士の承認・確認の実施証明・税法への適合を意味しません。**税理士への相談は利用者が行い、Ryoshuが相談先へ自動で送信することはありません。

## 法的な適否について

国税庁は、税務代理・税務書類の作成・税務相談という税理士業務を原則として税理士等に限定しています。また、反復継続する業務は必ずしも有償である必要がないと説明しています。注意書きや無料配布だけで、個別の提供行為が適法になるとは限りません。

ここでは一般的な業務範囲を紹介しているだけで、Ryoshuの機能や提供方法を評価した法律意見ではありません。Ryoshuは税務相談・申告代理・申告書の作成を提供せず、機能と提供方法について弁護士・税理士による法務審査も受けていません。
