# ChatGPTで帳簿を編集する（任意）

この機能はv1.1.0で追加しました。OCR・取り込み時の科目判断・通常の帳簿編集はローカルで動き、ChatGPTを接続せずに使えます。旧版v1.0.0の配布ZIPには、チャット編集は含まれません。

旧版からコードを更新した場合は、停止してから「初回セットアップ.cmd」で必要なライブラリを更新し、起動し直してください。

## 使い方

1. 経費帳の左端で編集する明細を選び、**「選択分をチャットで編集」**を押します。一度に50件までです。1件だけなら、明細の**「チャットで編集（任意）」**を使います。入力中の変更は先に保存してください。
2. **Continue with ChatGPT**を押すと、別タブにOpenAIのログイン画面が開きます。利用者自身でログイン・接続を許可してください。画面が見つからない・開かない場合は、チャット画面の**「ChatGPTの接続画面を開く」**から開けます。「設定・保存」の「接続・利用設定」から先に接続することもできます。
3. **「利用できるモデルを取得」**から、その接続先で使えるモデルを選びます。利用可否・プランの上限はアカウント・ワークスペース等により異なります。利用枠やクレジットの設定は[ChatGPTの使用量設定](https://chatgpt.com/settings/usage)で確認してください。
4. **「送信する明細を確認」**を開いて内容を確かめ、メッセージを入力します。送信のチェックを入れ、**「OpenAIに送って変更案を作る」**を押します。
5. 変更前・変更後を見比べ、よければ**「この変更案を未確認で保存」**を押します。案を取り消すか、会話で依頼し直すこともできます。

接続待ちは10分で終了します。時間切れの場合は、チャット画面の接続ボタンからやり直してください。接続待ちの途中でやり直す場合は、先に「接続待ちをやめる」を押します。再試行するときは新しく開いたログイン画面を使ってください。

依頼例：「選んだ明細の科目を通信費にして」「この3件の事業割合を50%にして」「用途を『案件Aの資料作成』にそろえて」「金額は変えず、摘要だけ短くして」。変更内容が曖昧な場合はAIに質問させ、推測で埋めないよう指示していますが、実際の案は利用者が確認してください。

編集できる項目は、取引日、支払先、合計金額、購入内容・摘要、勘定科目、支払元、事業割合、業務用途、記載税率・税額・登録番号、会計ソフト出力用の税区分です。科目は登録済みの選択肢から使います。独自の科目を追加するときは、先に「勘定科目」画面で登録してください。領収書の追加・削除、科目マスターそのものの編集、確認済みへの登録はチャットの対象外です。

## 変更と確認

チャットの返信だけでは帳簿を変更しません。適用後も**未確認**として保存します。確認済み明細を変更した場合は、以前の確認済み仕訳を無効にして再確認待ちに戻します。金額・科目・用途を原本と照合し、税務上の最終判断は税理士に確認してください。AIによる税務の確定判断は提供しません。

複数明細はまとめて保存します。1件でも別の操作で更新されていれば、全件を変更せず止めます。画面を更新して依頼し直してください。同じ編集案を再適用しても重複保存しません。編集案と会話の期限は30分、会話は10往復までです。モデルや接続先・対象明細が変わった場合は新しい会話にします。

適用が終わったら会話を新しくし、送信のチェックを外します。入力中の文章は「会話を新しくする」を押しても残します。別タブなどで接続先が変わった場合は送信を止め、モデルと送信内容の確認をやり直します。

保存の返事が届かなかった場合、すでに保存されている可能性があります。案を取り消したことにはせず、「保存結果を確認（未保存なら適用）」で同じ案の結果を確認します。この操作は、未保存ならその案を適用し、保存済みなら再保存しません。結果が不明な間は新しい依頼や案の取り消しを止めます。ダイアログを閉じても、このタブでは未確認の結果を保持します。

## OpenAIへ送る内容

- 選んだ明細の上記入力項目と、その識別ID。
- 登録済みの勘定科目名・説明。
- 同じ会話で送ったメッセージとAIの返信。

画像・PDF・OCR本文・原本ファイル名・選択していない明細・設定の事業概要は送りません。メッセージに自分で入力した情報は送信されます。秘密情報は入力しないでください。送信へのチェックは、開き直しや新しい会話、接続切り替えで外れます。

リクエストは`store:false`で送ります。これはOpenAI側で一切の保持がないことを保証する設定ではありません。OpenAIでの扱いは利用するアカウントの契約・設定・ポリシーを確認してください。

## 接続情報と解除

認証はOpenAIが公開する[ローカルOSS向けSign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)を使います。APIキー、Codexの既存ログイン情報、他のアプリの認証ファイルは使いません。Ryoshu用に許可した接続を保存します。

接続情報は帳簿とは別の`%USERPROFILE%\StudioYebisu\ReceiptLedger\auth`に保存します。WindowsではDPAPIで、このPCの同じ利用者だけが復号できる形にします。帳簿のバックアップZIP、CSV、ブラウザーの保存領域、Gitには含めません。保存済み接続は、同じメールアドレスでも登録別に区別します。別PCへの移行時は再接続してください。Windows以外では所有者だけが読み書きできるファイルに保存しますが、アプリ全体の動作は未検証です。

**「この接続を解除」**で、更新用のセッションをOpenAI側でも失効させ、このPCのトークンを消します。通信障害などで失効が確認できない場合は画面で知らせます。[ChatGPTの設定](https://chatgpt.com/settings/usage)からも接続を解除してください。接続解除は帳簿や変更履歴を消しません。

初回登録の途中で失敗した場合は、発行済みのアプリ登録IDだけを保持し、同じ登録から再試行します。本人情報の検証が終わるまでは、アカウントや推論用の接続として使いません。別の接続を登録し直すときは「未完了の登録を破棄」を選びます。

## 実装・検証の範囲

通信先は`auth.openai.com`と`api.openai.com`のHTTPSに限定します。外向き通信の許可はOAuth・チャットの処理中だけ、その処理の実行スレッドに与えます。OCR処理の通信制限は維持します。APIキーや別の課金経路へ自動で切り替えることはありません。

state・PKCE・nonce、公開鍵によるIDトークン署名・issuer・audience・期限・本人情報を検証します。更新トークンはプロセス間ロックで直列に更新します。推論は[公式Responses API](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)を使い、[プレビュー仕様](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)に従って`store:false`・`stream:true`とし、完了イベントまで確認します。モデルにファイル・シェル・SQLなどの実行権限は渡しません。

自動テストは架空の認証・モデル応答を使います。別に、実アカウントのOAuth許可と、実モデル`gpt-6-luna`との2往復で架空2明細の編集を確認しました。説明だけの返信、変更前後の表示、明示保存、未確認状態、選択外の保持、同じ案の再適用を照合しています。すべてのアカウント・モデルでの利用可否や編集精度を測ったものではありません。公開済みv1.0.0の100枚OCR検証とは別の検査です。
