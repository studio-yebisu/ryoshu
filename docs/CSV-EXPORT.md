# CSV出力

## 形式を選んで内容を確かめる

「CSV出力」で取り込み先・出力内容・対象期間を選択します。保存する前に、画面の件数・行数・借貸合計・出力できない項目・先頭5行を確認してください。

| CSVの形式 | 内容 | 文字コード・列 |
| --- | --- | --- |
| 汎用CSV | 確認済みの経費帳、仕訳、または未確認を含むOCR候補一覧 | UTF-8 BOM・見出しあり |
| freee | 振替伝票の他社会計ソフトインポート | UTF-8 BOM・17列・表題行と明細行の識別あり |
| MFクラウド | 会計帳簿 → 仕訳帳 → インポート → 仕訳帳 | UTF-8 BOM・公式27列・見出しあり |
| 弥生 | 弥生会計／やよいの青色申告の仕訳インポート | Shift-JIS（CP932）・25列・見出しなし |

- 未確認の下書きも、汎用CSVの「明細一覧（未確認を含む）」で保存できます。状態・確認理由・エラー・原本名・証憑ID・SHA-256を含みます。
- freee・MFクラウド・弥生向けの仕訳CSVは、確認済みにした明細だけを出力します。
- freeeでは名称列と税込金額を指定します。口座と科目の対応は取り込み先で確認し、未決済取引と支払管理は作りません。
- 弥生はデスクトップ版の25項目形式です。Next・オンラインの専用形式とは別です。

**書き出したCSVと原本ファイルは暗号化されない通常のファイルです。**保存先と共有先を管理してください。金額・科目・用途は原本と照合し、税務上の最終判断は利用者と税理士が行います。CSVを作成できることは税務上の承認を意味しません。[確認方針](REVIEW-POLICY.md)

## 確認状態と金額

- 経費帳・仕訳・会計ソフト向けCSVには、確認済みの取引だけを含めます。読み取り中・失敗・未確認・対象外は出力しません。
- 帳簿に残した仕訳がCSVの基盤で、無効にした過去の仕訳は含めません。
- 共用支出を事業用の現金等から払った場合は私用分を事業主貸とし、貸方は複合仕訳全体で一度だけ記録します。
- 個人立替では事業分のみを事業主借にします。
- 取り込み先に同じ明細がないかも確認してください。

## 消費税の欄

税率・税額・登録番号は領収書の記載を残す項目です。会計ソフトで使う税区分とは別に扱い、T番号だけで適格性を、印字税率だけで仕入税額控除を判断しません。

税額は、請求全体・今回領収分・明細のどれに関する金額かを分けて候補にします。今回の支出に対応する額を特定できなければ、明細の合計や税込額からの逆算をせず空欄にします。1回線分や契約全体の税額を今回分と混同していないか、原本で確かめてください。

「会計ソフトへ出す消費税区分」の選択肢は、対象外、非課税仕入、10%・軽減8%の確認済み課税仕入、経過措置です。未確認の明細があると会計ソフト向けCSVは保存せず、その領収書を開けるように案内します。免税事業者は「免税事業者として全行を対象外にする」を明示的に選択できます。標準では明細ごとに確認した区分を使います。

経過措置の名称とインボイス区分は取引日で変換し、対象は2023年10月から2031年9月までです。期間外は出力しません。8%と10%が混在する取引を単一税率に変換せず、Ryoshuで税率別・品目別に入力を分けることもできません。内訳は汎用CSVと原本を使って会計ソフト側で分けてください。

金額は税込です。申告に使う税額の計算は取り込み先で行います。MFの税額欄は公式指定どおり0にし、freeeは税込金額、弥生は税込経理の形式で使います。税抜金額として読み込まないでください。

## 科目名・文字・内訳

- 「科目の出力名を合わせる」で設定するのは、帳簿の科目名と取り込み先の名称の対応です。形式ごとに帳簿の暗号化DBの設定へ保存し、科目マスターは変更しません。
- 取り込み先の文字数制限を超える場合は、自動で短くせずに修正対象として表示します。
- 補助科目を管理していないため、会計ソフト向けCSVの借方・貸方補助科目欄は空欄です。freeeの口座名・取引先・品目と、MFクラウド・弥生の補助科目は別のものです。[勘定科目と補助科目の考え方](ACCOUNTS.md)
- 部門は出力しません。freee・MFクラウドの取引先列には支払先名を記載します。freeeでは未登録の名前が新しい取引先タグになるため、表記ゆれは保存前に整えるか取り込み先で確認してください。

摘要は、freeeでは1,024文字、MFでは200文字、弥生では半角64桁が上限です。超える分は短縮してプレビューに表示します。弥生の仕訳メモには証憑IDを先頭に残し、全文は汎用CSVと原本で確認できます。

弥生の摘要・メモの`m³`などの単位と丸数字は標準表記に変換し、内容をプレビューに示します。科目名は変更しません。絵文字や異体字などCP932で表せない文字が残る場合は、`?`に置き換えずに出力を止めます。CSVの改行・カンマ・引用符はエスケープし、数式として開かれる可能性のある文字列は無効化します。

## まとめて確認する

「選択した明細をまとめて確認」では、空欄の用途・事業割合・支払元・会計ソフト出力用の税区分にだけ共通値を入力できます。入力済みの値は上書きせず、8%・10%の混在する明細は個別に確認します。

「この形式でCSVを作成した明細を除く」を有効にすると、同じ形式・種類で作成済みの版を除外します。修正した明細は新しい版として対象に戻り、無効にすれば再出力できます。

履歴はCSVを生成した記録で、ファイルの保存や会計ソフトへの取り込みが成功した証拠ではありません。保存できなかった場合や再出力が必要な場合は除外を解除し、取り込み先でも重複を確認してください。

## 検証と出典

`scripts/verify_csv_workflow.py`の検査では、免税の架空個人事業主として6件を手動確認し、取込・登録・プレビュー・出力の各APIを通しています。各形式で7行の複合仕訳を再読込し、借方・貸方とも299,095円の一致を確認しました。内訳は事業分296,877円、私用分2,218円です。OCR・AIの正答率とは別の出力検査です。

2026-10-21に各社の公式資料を確認しました。

- [freee：その他の会計ソフトから仕訳データを移行する](https://support.freee.co.jp/hc/ja/articles/204847430) — 必須列、表題行・明細行、伝票番号、取込経路。公式UTF-8テンプレートも確認。
- [freee：インボイス制度導入後の記帳](https://support.freee.co.jp/hc/ja/articles/23502084589593) — 確認済み課税仕入と経過措置の税区分名。
- [MF：仕訳帳をインポートする](https://biz.moneyforward.com/support/account/guide/import-books/ib01.html) — 27列、複合仕訳、税額欄、インボイス区分。
- [MF：税区分の一覧](https://biz.moneyforward.com/support/account/faq/service/s15.html) — 税区分の名称。本文の取得制限があるため、公開検索結果でも名称を確認。
- [弥生：仕訳データの項目と記述形式](https://support.yayoi-kk.co.jp/subcontents.html?page_id=18545) — 25列、識別フラグ、複合仕訳、長さ制限。
- [弥生：税区分の記述形式](https://support.yayoi-kk.co.jp/faq_Subcontents.html?page_id=27165) — 税込区分とインボイス区分の表記。

実サービスの利用者アカウントへはデータを送信していません。確認したのは、公式形式との照合、ローカルPC上での生成と再読込、アプリのAPIと画面です。
