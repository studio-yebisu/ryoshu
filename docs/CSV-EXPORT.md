# CSV出力（v0.4.0）

デフォルトでは、取り込み後に作った未確認の帳簿も汎用CSVで保存できます。Freee・MFクラウド・弥生へ取り込む仕訳CSVには、あとから確認済みにした明細を出力します。

経費帳の「帳簿をCSVで持ち出す」で、期間、出力先、内容を選びます。保存前に件数、行数、会計ソフト向けの借貸合計、出力できない項目、先頭5行を確認できます。

| 出力先 | 内容 | 文字コード・列 |
| --- | --- | --- |
| 汎用CSV | 確定済みの経費帳、仕訳、または確認待ちを含むOCR候補一覧 | UTF-8 BOM・見出しあり |
| freee | 振替伝票の他社会計ソフトインポート | UTF-8 BOM・17列・表題行と明細行の識別あり |
| MFクラウド | 会計帳簿 → 仕訳帳 → インポート → 仕訳帳 | UTF-8 BOM・公式27列・見出しあり |
| 弥生 | 弥生会計／やよいの青色申告の仕訳インポート | Shift-JIS（CP932）・25列・見出しなし |

freeeは名称列と税込金額を指定して取り込みます。取込先で口座や科目との対応を確認してください。振替伝票としての出力なので、freeeの未決済取引や支払管理は作成しません。弥生はデスクトップ版の25項目形式です。Next・オンラインの専用形式とは分けています。

## 確定と金額

会計ソフト向けと汎用の経費帳・仕訳は、利用者が確認して登録した取引だけを出力します。確認待ち、読取中、エラー、対象外は混ぜません。OCR候補をまとめて見たい場合は、汎用CSVの「OCR候補・確認待ちを含む一覧」を使います。状態、確認理由、エラー、原本名、証憑ID、SHA-256も残します。

出力の元はSQLiteに保存された仕訳です。事業用の現金等で支払った私用分は事業主貸に分け、複合仕訳の中で貸方を一度だけ記録します。個人立替は事業分だけを事業主借へ計上します。古い無効の仕訳は出力しません。取込先で再取込すると重複することがあるため、既存データとの重複を確認してください。

## 消費税

領収書に印字された税率・税額・登録番号と、会計ソフトで使う税区分は別の欄です。T番号だけで適格性を決めたり、印字税率だけで仕入税額控除を決めたりしません。

領収書の確認画面の「会計ソフトへ出す消費税区分」で、対象外、非課税仕入、10%・軽減8%の確認済み課税仕入、または経過措置を選べます。確認前の取引があると会計ソフト向けの保存を止め、該当の領収書へ戻れるように表示します。利用者が免税事業者の場合は、出力画面で「免税事業者として全行を対象外にする」を明示的に選べます。通常の初期値は個別確認です。

経過措置を選んだ場合は、取引日に応じた各ソフトの名称・インボイス区分へ変換します。対応期間は2023年10月から2031年9月までです。期間外は出力を止めます。8%と10%が混在する取引を単一税率へ自動変換しません。内訳を分けるか、汎用CSVで持ち出して確認してください。

金額は税込です。税額の申告計算は取込先で行います。MFの税額欄は公式指定に従って0とし、freeeは税込金額の設定、弥生は税込経理の形式で使用します。税抜金額として読み込まないでください。

## 文字と科目の対応

「科目の出力名を合わせる」で、アプリ内の科目名と出力先の科目名を対応付けられます。対応はソフトごとにこのPCへ保存し、元の帳簿は保持します。取込先の長さ制限を超える科目名は黙って切らず、確認が必要な項目として表示します。

摘要の長さ制限は、freee 1,024文字、MF 200文字、弥生 半角64桁です。長い摘要は出力時に短縮し、その旨をプレビューに表示します。弥生の仕訳メモには証憑IDを先頭に残します。全文は汎用CSVと原本にあります。

弥生の摘要・メモでは、`m³`のような単位や丸数字などを標準表記へ変換し、変換をプレビューに表示します。科目名は自動改名しません。絵文字や異体字など、CP932で表せない文字が残る場合は出力を止めます。値を`?`へ置換しません。CSVの改行・カンマ・引用符はエスケープし、数式として開かれ得る文字列は無効化します。

## 検証と出典

`scripts/verify_csv_workflow.py`は、架空の免税個人事業主として6件を手動確認し、実際の取込・登録・プレビュー・出力APIを通す検査です。7行の複合仕訳を各形式で再読込し、借貸とも299,095円で一致することを確認します。事業分296,877円、私用分2,218円です。この出力検査とOCR・AIの正答率は別集計です。

2026-10-21に各社の公式資料を確認しました。

- [freee：その他の会計ソフトから仕訳データを移行する](https://support.freee.co.jp/hc/ja/articles/204847430) — 必須列、表題行・明細行、伝票番号、取込経路。公式UTF-8テンプレートも確認。
- [freee：インボイス制度導入後の記帳](https://support.freee.co.jp/hc/ja/articles/23502084589593) — 確認済み課税仕入と経過措置の税区分名。
- [MF：仕訳帳をインポートする](https://biz.moneyforward.com/support/account/guide/import-books/ib01.html) — 27列、複合仕訳、税額欄、インボイス区分。
- [MF：税区分の一覧](https://biz.moneyforward.com/support/account/faq/service/s15.html) — 税区分の名称。本文の取得制限があるため、公開検索結果でも名称を確認。
- [弥生：仕訳データの項目と記述形式](https://support.yayoi-kk.co.jp/subcontents.html?page_id=18545) — 25列、識別フラグ、複合仕訳、長さ制限。
- [弥生：税区分の記述形式](https://support.yayoi-kk.co.jp/faq_Subcontents.html?page_id=27165) — 税込区分とインボイス区分の表記。

実サービスの利用者アカウントへデータを送信する操作は行っていません。検証範囲は公式形式との照合、ローカルでの生成・再読込、アプリのAPIと画面です。
