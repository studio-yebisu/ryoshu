# 勘定科目の選択と分類の範囲

[README](../README.md) / [使い方](GUIDE.md) / [CSV出力](CSV-EXPORT.md)

初期データは、個人事業主の支出を整理するための**74科目（経費49・資産20・支払元等5）**です。領収書に設定できる経費・資産は**69科目**で、13の支出カテゴリーから探せます。必要なら独自科目を追加できます。

## 明細の科目を選び直す

「読み取り結果」の勘定科目名を開き、**カテゴリー→勘定科目**の順に選択して保存します。未選択なら「科目を選ぶ」から始めます。カテゴリーだけを変更しても科目は自動選択されません。金額・日付・用途は「詳細を修正」で編集します。

確認済みの明細では、科目だけを変えても未確認へ戻ります。以前の仕訳は履歴に残り、再確認するまで確認済みだけを出力するCSVには含まれません。科目以外の入力値は保持します。

選択画面のカテゴリーは、科目を探すためのRyoshu独自の整理です。補助科目としてCSVに出るものではなく、出力には選択した正式な勘定科目名を使います。取り込み先の名称が異なる場合は「科目の出力名を合わせる」で対応付けてください。

## ☆のよく使う科目

**☆**を押すと「よく使う科目」に追加でき、**★**で解除できます。科目選択画面・「詳細を修正」・「勘定科目一覧」から操作でき、独自に追加した経費・資産科目にも使えます。

登録した科目は選択画面の上に並びます。☆の情報は帳簿の暗号化DBに保存され、再起動と暗号化バックアップからの復元後にも引き継がれます。

☆を付け外しするだけで、領収書の科目・確認状態・仕訳・AI候補・CSVの科目名は変わりません。よく使う科目から選択した後は、ほかの科目と同じように変更を保存してください。

## カテゴリーと初期科目

| カテゴリー | 科目 |
| --- | --- |
| 文具・備品 | 消耗品費、事務用品費 |
| 通信・IT | 通信費 |
| 交通・車両 | 旅費交通費、車両費、燃料費 |
| 家賃・設備 | 地代家賃、水道光熱費、修繕費、賃借料、リース料、衛生費、管理費 |
| 営業・販売 | 会議費、接待交際費、広告宣伝費、荷造運賃、印刷製本費、販売促進費、販売手数料 |
| 資料・学習 | 新聞図書費、研修費、研究開発費、取材費 |
| 外注・専門家 | 外注工賃、支払報酬料、外注費 |
| 人件費・福利厚生 | 福利厚生費、給料賃金、雑給、採用教育費、賞与、専従者給与、退職金、退職金掛金、法定福利費 |
| 税金・保険・金融 | 支払手数料、損害保険料、租税公課、利子割引料、支払利息 |
| 仕入・製造 | 仕入高、材料費 |
| 農業 | 種苗費、肥料費、農薬衛生費、農具費 |
| 資産・開業 | 工具器具備品、ソフトウェア、車両運搬具、前払費用、長期前払費用、一括償却資産、開業費、開発費、建物、建物附属設備、構築物、機械装置、土地、敷金、差入保証金、前払金、商品、原材料、仕掛品、貯蔵品 |
| その他の経費 | 諸会費、雑費 |
| 支払元・事業主 | 現金、普通預金、未払金、事業主借、事業主貸 |

現金・普通預金・未払金・事業主借・事業主貸は、支払元に応じて仕訳の相手側に使います。領収書の経費・資産を選ぶ画面には支出用のカテゴリーを表示し、勘定科目一覧ではこれらの科目も確認できます。

事務用品費・販売促進費・外注費・支払利息・リース料は独立した正式科目です。旧版で消耗品費・広告宣伝費・外注工賃・利子割引料・賃借料として保存した明細は変更しません。

経費にできるかや消費税の扱いは、科目名から自動的に決めません。家事関連費・従業員や親族への支払・前払・敷金・棚卸資産は、実際の使い方・期間・契約を確かめます。資産の支出は経費と分けて集計し、減価償却・期末棚卸・決算調整は会計ソフトや税理士で確認してください。

## 勘定科目・補助科目・税区分の違い

| 分けるもの | 例 | 確かめること |
| --- | --- | --- |
| 勘定科目 | 通信費、旅費交通費、消耗品費 | 購入内容と業務での用途。同じ店で買っても同じ科目になるとは限りません |
| 補助科目 | 通信費の内訳として「携帯電話」「ネット回線」 | 内訳ごとに集計する必要があるか、取り込み先でどの分類を使っているか |
| 消費税区分 | 課税仕入10%、軽減8%、対象外など | 印字税率とは別に、事業者の立場や取引内容・請求書の要件を確認します |
| 事業で使う割合 | 仕事と私用を兼ねる通信費の事業分 | 使用時間など、事業分を区分する根拠。AIが一律の割合を決めるものではありません |

事業用のネット回線代は「通信費」で十分に管理できる場合もあれば、携帯電話代と分けて集計したい場合もあります。後者には内訳が必要です。分類を増やしても、経費や消費税の取扱いが自動で決まるわけではありません。

## Ryoshuで扱う範囲

**1領収書につき1つの経費・資産科目を扱います。**独自科目は暗号化DBへ追加できますが、補助科目の登録と内訳集計、領収書内の品目を複数科目へ分ける機能はありません。会計ソフト向けCSVの補助科目欄は空欄です。

内訳を管理する場合は、購入内容と業務用途を記録し、CSVを取り込んだ会計ソフトで補助科目を設定してください。freeeでは口座名・取引先・品目が補助科目に相当する情報を扱います。MFクラウド・弥生との違いは取り込み先で確認してください。

## 1枚に別の支出が混ざる場合

科目の内訳を分けることと、同じ領収書にある事務用品と私用品を分けることは別の作業です。後者では、品目ごとの用途と金額を確認する必要があります。判別できないものをまとめて雑費にしたり、事業用100%にしたりしないでください。

複数科目への分割や、8%と10%の混在を税率別に処理するときは、汎用CSVと原本を使って会計ソフト側で分けます。PDFのページ分割は1ページに1枚の領収書を取り込む機能で、領収書内の品目を分ける機能ではありません。

高額な機器や年払いの費用では、資産と期間配分を検討してください。Ryoshuは候補と確認事項を表示しますが、減価償却・決算・申告の計算は行いません。
