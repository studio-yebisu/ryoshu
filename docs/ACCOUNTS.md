# 収録している勘定科目と判定の範囲

[README](../README.md) / [使い方](GUIDE.md) / [CSV出力](CSV-EXPORT.md)

勘定科目は取引の内容を整理する分類です。日本全体で共通の「全何科目」という固定の数を使うものではなく、業種や会計ソフト、管理したい内容に応じて科目を設けます。Ryoshuの初期データは、個人事業主の領収書による支出を扱うための**38科目（経費28・資産5・支払元等5）**です。日本の会計科目全体を網羅する数ではありません。

通信費・消耗品費・旅費交通費などは、別々の科目としてSQLiteに保存されています。通信費の用例には、電話・インターネット・レンタルサーバーを登録し、品目辞書でも回線・サーバー・ドメインなどを区別して科目候補を絞ります。店名だけで一律に科目を割り当てるものではありません。

基本科目よりさらに内訳を見たい場合には「補助科目」を設ける方法もあります。これは通信費と消耗品費を分類することとは別です。

## 初期データの38科目

### 資産5科目

工具器具備品、ソフトウェア、車両運搬具、前払費用、長期前払費用。

### 支払元・事業主勘定等5科目

現金、普通預金、未払金、事業主借、事業主貸。

費用と資産が領収書に選べる33科目です。支払元などの5科目は、支払方法に応じた仕訳の相手科目として使います。独自の科目を追加すると、利用者のDBの科目数は増えます。

## 勘定科目・補助科目・税区分の違い

| 分けるもの | 例 | 確かめること |
| --- | --- | --- |
| 勘定科目 | 通信費、旅費交通費、消耗品費 | 購入内容と業務での用途。同じ店で買っても同じ科目になるとは限りません |
| 補助科目 | 通信費の内訳として「携帯電話」「ネット回線」 | 内訳ごとに集計する必要があるか、取り込み先でどの分類を使っているか |
| 消費税区分 | 課税仕入10%、軽減8%、対象外など | 印字税率とは別に、事業者の立場や取引内容・請求書の要件を確認します |
| 事業で使う割合 | 仕事と私用を兼ねる通信費の事業分 | 使用時間など、事業分を区分する根拠。AIが一律の割合を決めるものではありません |

たとえば事業用のネット回線代は、「通信費」で集計できれば基本科目だけで管理できます。携帯電話代と別々に見たい場合に、内訳を追加します。細分化しても、科目名だけで経費になることや消費税の扱いが決まるわけではありません。

## Ryoshuで扱う範囲

初期データは38科目で、領収書に選べる経費・資産は33科目です。「勘定科目」画面で独自の経費・資産科目をSQLiteに追加できます。「科目の出力名を合わせる」では、取り込み先の科目名へ対応付けられます。

**v1.0.0は1領収書につき1つの経費・資産科目を扱います。** 補助科目の登録・内訳集計や、1枚の領収書の品目を複数科目へ分ける機能はありません。会計ソフト向けCSVの補助科目欄は空欄で出力します。独自科目の追加と、親の科目に紐づく補助科目の管理は別の機能です。

内訳を細かく管理したい場合は、購入内容・業務での用途を記録し、CSVを取り込んだ会計ソフトで補助科目を設定してください。freeeは補助科目に相当する情報を口座名・取引先・品目で扱います。MFクラウド・弥生との分類の違いは、取り込み先で確認します。

## 1枚の領収書に別の支出が混ざる場合

「通信費の内訳を携帯電話とネット回線に分ける」ことと、「1枚の領収書にある事務用品と私用品を分ける」ことも別です。後者では、品目ごとの用途や金額を確認する必要があります。AIが判別できない支出を、まとめて雑費や事業用100%にすることは避けます。

複数科目への分割や、8%と10%の混在を税率別に処理する必要がある場合は、汎用CSVと原本を使い、会計ソフト側で内訳を分けてください。RyoshuのPDFページ分割は「1ページに1領収書」のファイルを取り込む機能で、1枚の領収書の品目を分割する機能ではありません。

高額な機器や年払いの費用には、資産・期間配分の検討が必要なものもあります。Ryoshuは候補と確認事項を残しますが、減価償却や決算・申告の計算は行いません。
