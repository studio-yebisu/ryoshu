# 収録している勘定科目と判定の範囲

[README](../README.md) / [使い方](GUIDE.md) / [CSV出力](CSV-EXPORT.md)

個人事業主の支出を扱うための初期データは**74科目（経費49・資産20・支払元等5）**です。領収書の明細に設定できる経費・資産は**69科目**で、カテゴリーから絞り込んで選びます。業種や取り込み先に合わせて、独自科目も追加できます。

## 科目を変更する

「読み取り結果」の**勘定科目名（例：「通信費」）**をクリックし、**カテゴリー→勘定科目**の順に選んで保存します。カテゴリーを変えただけでは別の科目を自動設定しません。科目が未選択の明細では「科目を選ぶ」を押します。金額・日付・用途なども確認・修正する場合は、「詳細を修正」を開きます。

科目だけの変更でも、確認済みの明細は未確認に戻ります。前の仕訳は履歴として残し、再び確認済みにするまで、確認済みの明細を出力するCSVの対象から外れます。金額・用途・割合・支払元など、科目以外の入力は保持します。

カテゴリーは科目を探すための分類で、補助科目ではありません。CSVには選んだ正式な勘定科目名を出します。取り込み先の名前と異なる場合は「科目の出力名を合わせる」で対応付けてください。

## よく使う科目にスターを付ける

科目の横の**☆**を押すと、**「よく使う科目」**に追加できます。**★**を押すと解除します。勘定科目名をクリックして開く選択画面、「詳細を修正」、または「勘定科目」の一覧から登録できます。

スターを付けた科目は選択画面の上に並び、カテゴリーを探さずに選べます。スターはこの帳簿の暗号化DBに保存し、再起動や暗号化バックアップからの復元後も引き継ぎます。独自に追加した経費・資産科目も、よく使う科目に追加できます。

スターの追加・解除では、領収書の科目、確認済みの状態、仕訳は変わりません。「よく使う科目」から選んだ科目を明細へ反映するときは、通常どおり変更を保存してください。スターはAIの判定やCSVの科目名には影響しません。

支払元・事業主勘定等は、選んだ支払元に応じた仕訳の相手科目として使います。選択画面には支出に使えるカテゴリーを表示し、科目一覧では支払元の科目も確認できます。

事務用品費・販売促進費・外注費・支払利息・リース料を独立した正式科目として追加しました。以前の版で消耗品費・広告宣伝費・外注工賃・利子割引料・賃借料として保存した明細は変更しません。新たに選ぶ場合は、選択した正式科目を優先します。

科目名だけで必要経費への算入や税区分は決まりません。家事関連費、従業員・親族への支払、前払・敷金・棚卸資産などは、業務用途や期間、契約内容を確認してください。資産として選んだ支出は経費集計と分けて表示し、減価償却・期末棚卸・決算調整は会計ソフトや税理士と確認します。

## 勘定科目・補助科目・税区分の違い

| 分けるもの | 例 | 確かめること |
| --- | --- | --- |
| 勘定科目 | 通信費、旅費交通費、消耗品費 | 購入内容と業務での用途。同じ店で買っても同じ科目になるとは限りません |
| 補助科目 | 通信費の内訳として「携帯電話」「ネット回線」 | 内訳ごとに集計する必要があるか、取り込み先でどの分類を使っているか |
| 消費税区分 | 課税仕入10%、軽減8%、対象外など | 印字税率とは別に、事業者の立場や取引内容・請求書の要件を確認します |
| 事業で使う割合 | 仕事と私用を兼ねる通信費の事業分 | 使用時間など、事業分を区分する根拠。AIが一律の割合を決めるものではありません |

たとえば事業用のネット回線代は、「通信費」で集計できれば基本科目だけで管理できます。携帯電話代と別々に見たい場合に、内訳を追加します。細分化しても、科目名だけで経費になることや消費税の扱いが決まるわけではありません。

## Ryoshuで扱う範囲

初期データは74科目で、領収書の明細に設定できる経費・資産は69科目です。「勘定科目」画面で独自の経費・資産科目をSQLiteに追加できます。「科目の出力名を合わせる」では、取り込み先の科目名へ対応付けられます。

**1領収書につき1つの経費・資産科目を扱います。** 補助科目の登録・内訳集計や、1枚の領収書の品目を複数科目へ分ける機能はありません。会計ソフト向けCSVの補助科目欄は空欄で出力します。独自科目の追加と、勘定科目の内訳として使う補助科目の管理は、別の機能です。

内訳を細かく管理したい場合は、購入内容・業務での用途を記録し、CSVを取り込んだ会計ソフトで補助科目を設定してください。freeeは補助科目に相当する情報を口座名・取引先・品目で扱います。MFクラウド・弥生との分類の違いは、取り込み先で確認します。

## 1枚の領収書に別の支出が混ざる場合

「通信費の内訳を携帯電話とネット回線に分ける」ことと、「1枚の領収書にある事務用品と私用品を分ける」ことも別です。後者では、品目ごとの用途や金額を確認する必要があります。AIが判別できない支出を、まとめて雑費や事業用100%にすることは避けます。

複数科目への分割や、8%と10%の混在を税率別に処理する必要がある場合は、汎用CSVと原本を使い、会計ソフト側で内訳を分けてください。RyoshuのPDFページ分割は、1ページにつき1枚の領収書を収めたPDFを取り込む機能で、1枚の領収書の品目を分割する機能ではありません。

高額な機器や年払いの費用には、資産・期間配分の検討が必要なものもあります。Ryoshuは候補と確認事項を残しますが、減価償却や決算・申告の計算は行いません。
